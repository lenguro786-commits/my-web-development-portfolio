# Impact Connect — Community Development Website

**Live website:** https://scintillating-druid-9b2399.netlify.app/

## Overview
Impact Connect is a responsive website concept focused on community-led development, livelihood opportunities, youth empowerment, and community resilience.

## Key Features
- Responsive website layout for desktop and mobile
- Home, About, Projects, and Contact navigation
- Project focus areas for skills and livelihoods, youth opportunities, and community resilience
- Contact link designed to help visitors get in touch

## Technologies
- HTML5
- CSS3
- JavaScript

## Purpose
This project demonstrates my front-end web development skills and my interest in building accessible, practical digital experiences for community organisations and social-impact initiatives.
