# NGO Impact Dashboard — Nonprofit Reporting Web App

**Live project:** https://gleeful-dusk-0bd922.netlify.app/

## Overview
The NGO Impact Dashboard is a web application concept designed to present nonprofit programme information and impact indicators in an organised dashboard.

## Project Goals
- Present programme information clearly
- Make impact data easier to review
- Provide a structured dashboard layout
- Demonstrate a user-friendly interface for nonprofit organisations

## Technologies
- HTML5
- CSS3
- JavaScript

## Purpose
This project demonstrates my front-end development practice in designing dashboard-style interfaces for nonprofit and community development contexts.
