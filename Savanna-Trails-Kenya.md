# Savanna Trails Kenya — Safari and Tours Website

**Project case study:** https://contra.com/p/mABmZMPA-kenya-safaris-and-tours-or-savanna-trails-kenya

## Overview
Savanna Trails Kenya is a safari and tours website concept showcasing travel experiences in Kenya, with a focus on wildlife, landscapes, and personalised safari planning.

## Services Featured
- Maasai Mara Wildlife Safari (3–4 days)
- Amboseli Landscape and Wildlife Tour (2–3 days)
- Custom Safari Planning

## Key Features
- Home, Safaris and Tours, About, and Contact navigation
- Services presentation
- Testimonials section
- Contact form concept
- Search engine optimisation (SEO) considerations
- Responsive website design

## Technologies
- HTML5
- CSS3
- JavaScript
- AI-assisted development tools

## Purpose
This project demonstrates my ability to develop and present a tourism website concept with clear service information, user-friendly navigation, and a professional visual identity.
