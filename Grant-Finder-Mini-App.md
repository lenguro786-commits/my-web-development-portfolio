# Grant Finder Mini-App — Funding Discovery Tool

**Live project:** https://frolicking-cassata-ce57c2.netlify.app/

## Overview
The Grant Finder Mini-App is a web application concept designed to help users explore funding opportunities and organise their grant discovery process.

## Key Features
- User profile for funding preferences
- Grant discovery interface
- Funding information presented in a clear format
- Interactive elements for a practical user experience

## Technologies
- HTML5
- CSS3
- JavaScript
- Browser local storage

## Purpose
This project demonstrates my front-end development practice in building interactive web applications that support funding discovery and make information easier to organise.
